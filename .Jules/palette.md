## 2026-05-11 - Gated Celebration and Semantic Labels in Streamlit
**Learning:** Using `st.session_state` to gate terminal success animations (like `st.balloons`) prevents repetitive triggers on script reruns, improving UX for iterative tasks. Semantic labels in selectboxes (via `format_func`) with emojis enhance readability and accessibility compared to raw boolean or technical values.
**Action:** Always gate celebration animations with session state and prefer formatted labels for status-related filters.
