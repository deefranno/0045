## 2025-05-21 - [Gated Balloons and Progress Visualization]
**Learning:** For task-oriented apps like annotation tools, gating celebratory effects like 'st.balloons()' behind a 100% completion milestone (tracked via st.session_state) provides a clear reward signal, whereas firing on initial load can be distracting.
**Action:** Always pair completion-based metrics with visual progress bars and use session state to manage one-time celebratory triggers.
