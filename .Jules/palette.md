## 2025-05-15 - [Semantic Labeling in Selection Components]
**Learning:** Using raw technical values (like booleans) in user-facing selection components reduces clarity. Mapping these to semantic labels (e.g., "Has Issues" instead of "True") makes the interface more intuitive and accessible.
**Action:** Always use mapping functions (like Streamlit's `format_func`) to provide human-readable labels for technical data in UI controls.
