## 2025-05-22 - [Celebratory UX Gatekeeping]
**Learning:** For task-oriented apps like annotation tools, triggering celebratory effects (e.g., st.balloons()) only upon completion (100% progress) provides a more meaningful reward and reduces distraction compared to triggering on initial load.
**Action:** Always gate celebration UI behind a completion milestone and use session state to ensure it only triggers once per milestone achievement.
