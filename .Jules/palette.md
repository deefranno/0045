# Palette's UX Journal

## 2025-05-14 - Semantic Clarity in Data Evaluation
**Learning:** In data evaluation tools, labeling a completion checkbox as "Issue" (boolean) can be confusing. Users expect a "Reviewed" or "Annotated" status to track progress, separate from whether an issue was actually found.
**Action:** Use "Reviewed?" or "Status" for progress tracking, and "Category" or "Issue Type" for the qualitative evaluation.

## 2025-05-14 - Streamlit Layout Best Practices
**Learning:** Data-heavy applications in Streamlit significantly benefit from `layout="wide"` and `use_container_width=True`. This prevents horizontal scrolling and makes the interface feel more professional.
**Action:** Default to wide mode for data annotation/evaluation mockups.
