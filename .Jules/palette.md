## 2026-04-21 - [Persistent Success Feedback in Streamlit]
**Learning:** Using 'st.session_state' to gate animations like 'st.balloons' prevents repetitive annoyance, but persistent feedback like 'st.success' should remain visible as long as the completion condition is met to maintain context.
**Action:** Always separate one-time celebratory triggers from state-dependent status indicators in Streamlit apps.
